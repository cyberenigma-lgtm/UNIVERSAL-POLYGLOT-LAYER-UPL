# 🚀 UPL+ プログラミング言語 クイックスタートガイド
## 高性能決定論的システム言語 ＆ スタンドアロン C99 ネイティブコンパイラ

**UPL+ (Universal Polyglot Layer Plus)** の公式技術ドキュメントへようこそ。UPL+ は、極限のパフォーマンス、シリコンレベルの直接制御、真の多言語構文、そして誤差ゼロの金融 10 進演算 (COMP-3 BCD) のために設計された、**コンパイル型・静的型付け・完全自己完結型**のシステムプログラミング言語です。

---

### 🌟 UPL+ のアーキテクチャの柱

1. **自律型ネイティブコンパイラ (`uplc`)：** Python や重厚な LLVM に依存せず、純粋な ANSI C99 で構築。50 ミリ秒未満で高速ネイティブコンパイル。
2. **多言語グローバル構文：** 多言語キーワードを字句解析レベルで直接統一 AST ノードにマッピング。
3. **誤差ゼロの金融演算 (`comp3`)：** IEEE-754 浮動小数点の丸め誤差を排除した BCD パック 10 進型。
4. **ハードウェア直接制御 (`embed` / `asm`)：** C99 コードや x86_64 アセンブリを中間オーバーヘッドなしで関数内に直接インライン記述。
5. **アリーナメモリアロケータ：** 64 KB ブロック管理による決定論的メモリ運用で、メモリ断片化を根絶し $O(1)$ で瞬間解放。

### 📦 最初の UPL+ プログラム

```upl
module example;

pub fn main() -> i32 {
    let mut total: i32 = 0;
    let base: i32 = 1000;
    let tax: i32 = 10;

    total = base + (base * tax / 100);
    return 0;
}
```

### ⚡ コンパイルと実行

```bash
# ワンステップでコンパイル＆実行：
bin/uplc.exe run program.upl

# ネイティブバイナリのビルド：
bin/uplc.exe build program.upl -o bin/program.exe
```
