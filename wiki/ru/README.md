# 🚀 КРАТКОЕ РУКОВОДСТВО: ЯЗЫК ПРОГРАММИРОВАНИЯ UPL+
## Язык Системного Программирования и Нативный Компилятор C99

Добро пожаловать в официальную техническую документацию **UPL+ (Universal Polyglot Layer Plus)**. UPL+ — это **компилируемый, строго типизированный, полностью автономный язык системного уровня**, разработанный для обеспечения максимальной производительности, прямого взаимодействия с кремнием и точной десятичной финансовой арифметики.

---

### 🌟 Ключевые Архитектурные Принципы UPL+

1. **Автономный Компилятор (`uplc`) :** Написан на стандартном модульном ANSI C99 без каких-либо зависимостей от Python, виртуальных машин или сборщиков мусора.
2. **Многоязычный Синтаксис :** Прямая поддержка ключевых слов на десятках языков мира на уровне лексического анализатора.
3. **Точная Десятичная Арифметика (`comp3`) :** Упакованный BCD-формат для финансовых вычислений с нулевой погрешностью округления IEEE-754.
4. **Бесшовное Низкоуровневое Слияние (`embed` и `asm`) :** Встраивание чистого C99 и ассемблерных инструкций x86_64 без накладных расходов вызовов FFI.
5. **Арена-Аллокатор Памяти :** Детерминированное управление блоками по 64 КБ, исключающее фрагментацию памяти и освобождающее ресурсы за время $O(1)$.

### 📦 Ваша Первая Программа на UPL+

```upl
module example;

pub fn main() -> i32 {
    let mut total: i32 = 0;
    let base: i32 = 1000;
    let tax: i32 = 20;

    total = base + (base * tax / 100);
    return 0;
}
```
