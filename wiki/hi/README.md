# 🚀 त्वरित आरंभ मार्गदर्शिका: UPL+ प्रोग्रामिंग भाषा
## उच्च प्रदर्शन नियतात्मक सिस्टम भाषा एवं स्टैंडअलोन C99 मूल कंपाइलर

**UPL+ (Universal Polyglot Layer Plus)** के आधिकारिक तकनीकी प्रलेखन में आपका स्वागत है। UPL+ एक **संकलित (compiled), स्थिर रूप से टाइप की गई और पूरी तरह से स्वायत्त सिस्टम प्रोग्रामिंग भाषा** है, जिसे हार्डवेयर के सीधे नियंत्रण और सटीक वित्तीय दशमलव गणना (COMP-3 BCD) के लिए डिज़ाइन किया गया है।

---

### 🌟 UPL+ की मुख्य वास्तुकला विशेषताएँ

1. **स्वायत्त मूल कंपाइलर (`uplc`):** बिना किसी पायथन, भारी रनटाइम या कचरा संग्राहक (GC) के शुद्ध ANSI C99 पर आधारित।
2. **वैश्विक बहुभाषी समर्थन:** लेक्सर स्तर पर दुनिया की प्रमुख भाषाओं के कीवर्ड्स का सीधा समर्थन।
3. **शून्य-त्रुटि वित्तीय गणित (`comp3`):** बिना किसी फ्लोटिंग-पॉइंट त्रुटि के सटीक दशमलव गणना।
4. **सिलिकॉन-स्तरीय प्रत्यक्ष एकीकरण (`embed` और `asm`):** C99 कोड और x86_64 असेंबली निर्देशों का सीधा समावेश।
5. **एरीना मेमोरी आवंटक:** 64 KB ब्लॉकों में नियतात्मक मेमोरी प्रबंधन और $O(1)$ त्वरित विमुक्ति।

---

### 📦 आपका पहला UPL+ प्रोग्राम

```upl
module example;

pub fn main() -> i32 {
    let mut total: i32 = 0;
    let base: i32 = 1000;
    let tax: i32 = 18;

    total = base + (base * tax / 100);
    return 0;
}
```

---

### ⚡ कंपाइल और निष्पादित कैसे करें

```bash
# एक चरण में कंपाइल और चलाएँ:
bin/uplc.exe run program.upl

# मूल बाइनरी निष्पादन योग्य फ़ाइल बनाएँ:
bin/uplc.exe build program.upl -o bin/program.exe
```
